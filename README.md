## WePC 南非套餐：24.9 澳元买到什么，买不到什么

先把三条最容易误解的写清楚。

**原生 IP 不等于家宽。** WePC 南非标的是“原生 IP（非家宽）”，IP 归属在南非，但不是住宅宽带。TikTok 场景里，家宽 IP 和机房 IP 的信任度不一样，WePC 自己的说明也写了“产品定位 TikTok 使用，但不承诺流媒体解锁”。要家宽双 ISP，得看它美国、日本、英国、韩国、澳大利亚的节点。

**100Mbps 均需中转。** 这个标注指的是中国大陆方向访问要搭配中转线路。WePC 的深港 IEPL 中转不单独出售，必须已有 WePC 落地机才能用，还要有合理比例。买之前先想好自己的网络环境，或者确认有没有现成的中转可用。

**512MB 内存跑不了 WordPress。** 这个判断有依据：Azure 南非 B1ls 的 0.5GB 档就被明确评价为“跑 WordPress 不够用”。WePC 南非是同一档内存，装个轻量面板、跑脚本、做账号环境没问题，当普通建站主机不合适。

适合的人：需要南非归属地原生 IP、能接受中转、业务量不大，比如账号环境、轻量跨境业务。不适合的人：普通 WordPress 建站、要大内存、要家宽双 ISP、要 Windows（资料没有说明南非套餐支持 Windows，买前必须问客服）。

价格上，24.9 澳元/月约 114.5 元人民币，是 Vultr 约翰内斯堡 1核1GB（$5/月）的四倍左右。多出来的钱买的是南非原生 IP 和 WePC 的 TikTok 场景定位，配置本身并不占优。只建站的读者不该为这个溢价买单。

## 南非机房只有两个城市，WePC 没写是哪一个

## 常见问题

**南非 VPS 放约翰内斯堡还是开普敦？**
个人站和大多数业务放约翰内斯堡，5 家可选；访客集中在开普敦、公司项目又在用 AWS，才去开 af-south-1。Azure 的开普敦区是受限区，普通账户开不了。

**南非 VPS 能建站吗？**
能，但要选对配置。1–2 vCPU、2–4GB 内存是 brochure 站和博客的起点，WooCommerce 建议 4–8GB。WePC 南非的 512MB 不在这个范围里。

**WePC 南非是家宽吗？**
不是。标注是原生 IP（非家宽）。WePC 的家宽双 ISP 方案在美国、日本、英国、韩国、澳大利亚等节点，南非没有这个选项。

**南非 VPS 能用支付宝吗？**
Vultr、LightNode、UltaHost 可以，WePC 也支持支付宝、信用卡、PayPal（PayPal 付款要选澳元）。AWS、Azure、Oracle 只收信用卡，Oracle 还不收虚拟卡和预付卡。

**WePC 退款怎么算？**
